# Messi vs. Ronaldo — two-player soccer game

A 400 × 400 Python game created by Joon Ho Song in CMU CS Academy. Two players compete to score three goals. The program handles movement, ball possession, shooting, bounces, tackling, cooldowns, and scoring.

## Controls

| Player | Move | Shoot | Tackle |
| --- | --- | --- | --- |
| Messi | W A S D | Space | Q |
| Ronaldo | Arrow keys | Enter | / |

Press **R** to restart.

## Source and running the game

The original source is in [soccer_game.py](soccer_game.py). It was written for the CMU CS Academy `cmu_graphics` environment. The Messi and Ronaldo images are referenced by `cmu://` addresses in the code; those image files are not included here. GitHub can display the source but cannot play the game. Running it elsewhere requires CMU Graphics and access to those images or replacement assets. This code has not been verified as a standalone desktop game.

The source includes links crediting the player images; the images are not redistributed here.
